# La Tiendita — Catálogo de abarrotes

Sitio tipo catálogo para una pequeña tienda de barrio que está comenzando.

## Características
- Un único `index.html`.
- Diseño responsive para escritorio y móvil.
- Navegación por pantallas sin scroll vertical de página.
- Catálogo de productos organizado por categorías.
- Búsqueda, filtros y paginación.
- Precios referenciales expresados en bolivianos (Bs), editables.
- Pantalla de ubicación con enlace directo a la ubicación compartida en Google Maps.
- Modo claro/oscuro persistente.
- PWA con manifest e instalación.
- Service Worker con caché de recursos locales para uso offline tras la primera visita.

## Importante
Este proyecto usa el nombre provisional **La Tiendita**. Los productos y precios son ejemplos referenciales para una tienda que inicia; deben revisarse y ajustarse al inventario, marcas, presentaciones y precios reales. La ubicación se abre mediante el enlace de Google Maps proporcionado. No incluye contacto, carrito, pedidos, compras ni formularios.

## Ejecutar y publicar
Para probar PWA, servir por localhost o HTTPS. Para publicar, subir los archivos a la raíz de un repositorio GitHub y activar GitHub Pages desde Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
